v0.1.1 исправляет ложную остановку WASAPI-захвата с сообщением «Повторный или устаревший блок звука пропущен». Небольшой ADC-разброс нормализуется по точному числу сэмплов перед передачей обработчику. Все PCM-сэмплы сохраняются; проверки настоящих временных разрывов, крупных сбоев часов и потери звука остаются включены. Модель и веса не изменены. Полный комплект — 120 тестов; номер версии виден в заголовке окна.

Переносимое локальное приложение Windows x64: микрофон и WASAPI loopback, GigaAM Multilingual 220M CTC, русский интерфейс, явное разрешение на каждый сеанс, TXT/MD/DOCX/PDF. Приложение не входит во встречи и не использует аккаунты или API Teams/Zoom. Python, pip, Git и Docker пользователю не нужны; модель и runtime включены в ZIP.

1. Скачайте `GigaAM-Meeting-windows-x64.zip` и полностью распакуйте в новую локальную папку.
2. Откройте `GigaAM-Meeting.exe`, выберите микрофон, звук наушников и папку экспорта.
3. Получите согласие участников, отметьте разрешение и нажмите «Начать». После остановки дождитесь завершения обработки и сохраните текст.

Сборочный конвейер проверяет 120 тестов, настоящий CPU-inference, сравнение кода внутри EXE с исходниками, PE-зависимости, экспорт и выборку TCP/UDP endpoints процесса. Выпуск публикуется только после успешного завершения этих проверок. Точные результаты конкретного EXE и границы сетевого аудита находятся в `provenance` его ZIP; SHA256, манифест файлов и DLL-аудит приложены к Release. Исторические RU/EN и streaming-измерения приведены с обозначением версии в `docs/TESTING.md`.

**Предварительная версия.** Живой захват микрофона/наушников, смена устройств, длительный реальный звонок, казахская и естественная смешанная речь ещё требуют пользовательской проверки. Короткие публичные примеры RU/EN не доказывают точность любого разговора. Чистая Windows без установленного Python и физическое отключение интернета не проверены; ограничения сетевой проверки описаны в `docs/PRIVACY.md`.

Захватываются все приложения на выбранном устройстве воспроизведения. Захвата отдельного процесса, определения людей и акустического эхоподавления нет; используйте наушники. Сохранение аудио выключено по умолчанию. При перегрузке видны задержка и пропуски. EXE не подписан: при блокировке соблюдайте правила организации, защиту Windows не отключайте.
