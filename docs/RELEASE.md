v0.1.2 добавляет отключаемый фильтр дублей динамиков в транскрипции микрофона. Сопоставляются порядок слов, близкое время и сильное совпадение PCM. Системный текст сохраняется, подтверждённые повторы микрофона убираются из отображения и экспорта. Короткие ответы, независимая речь и неопределённые совпадения сохраняются. Микрофон не отключается, исходное аудио/WAV не изменяется. Модель GigaAM Multilingual 220M CTC, веса и зависимости не менялись.

1. Скачайте `GigaAM-Meeting-windows-x64.zip` и полностью распакуйте в новую локальную папку.
2. Откройте `GigaAM-Meeting.exe`, выберите микрофон, звук компьютера и папку экспорта. Фильтр дублей включён по умолчанию для двух источников; его можно отключить перед сеансом.
3. Получите согласие участников, отметьте разрешение и сами нажмите «Начать». После остановки дождитесь завершения обработки и сохраните TXT/MD/DOCX/PDF.

Python, pip, Git и Docker пользователю не нужны. Приложение не входит во встречи, не создаёт участника, не использует аккаунты или API Teams/Zoom и не загружает модель при запуске. Аудиозапись выключена по умолчанию.

**Проверки:** 149 source-тестов, Ruff, настоящее локальное распознавание публичного WAV и его искусственного эха: 26 слов в каждом канале, 26 повторов убраны, системный текст сохранён. Перед публикацией конкретный EXE проходит source attestation, frozen self-test с этим же проверяемым эхом, экспорт, выборку TCP/UDP endpoints и PE DLL-аудит. Точные результаты и границы проверки находятся в `provenance` ZIP; SHA256, manifest и DLL-аудит приложены к Release. Тесты используют публичные/синтетические данные, записи пользователя не публикуются.

**Предварительная версия.** Это фильтр дублей текста, не полноценное акустическое эхоподавление. При реверберации, искажениях, несовпадающем ASR, коротких ответах или неубедительном звуковом совпадении дубли могут оставаться. Дубль может сначала отображаться, затем исчезнуть после обработки другого канала. Очень тихая речь поверх громкого эха неоднозначна; при таком сценарии отключите фильтр. Наушники уменьшают само эхо. Подробности: `docs/ECHO.md`.

Захватывается весь выбранный выход, включая другие приложения. Захвата отдельного процесса, определения людей и очистки WAV от эха нет. Живой акустический тест v0.1.2, длительный реальный звонок, казахская и естественная смешанная речь требуют дальнейшей проверки. Чистая Windows без установленного Python и физическое отключение интернета не проверены; границы сетевого аудита описаны в `docs/PRIVACY.md`. EXE не подписан: защиту Windows не отключайте.
